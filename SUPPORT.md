# Support

## Start here

Before opening a request:

1. Check the latest release notes in [CHANGELOG.md](CHANGELOG.md).
2. Search existing issues for the exact error or behavior.
3. Confirm the problem still occurs on the latest Noturcode release.
4. Export or copy only diagnostics that are safe to share.

## Bugs

Open a bug report using the repository's bug form. Include:

- Noturcode and macOS versions.
- Mac model and display arrangement when the issue affects the notch or multiple monitors.
- Coding harness and version, such as Claude Code or Codex.
- Terminal or editor and whether tmux, Zellij, or SSH is involved.
- Clear reproduction steps and expected versus actual behavior.
- Redacted logs, screenshots, or a short recording when useful.

## Questions and ideas

Use GitHub Discussions for setup questions and workflow conversations. Use the feature request form when proposing a concrete product change.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Privacy reminder

Noturcode works with local terminal and agent-session data. Remove secrets, private source code, personal paths, prompts, and transcript content before sharing logs or screenshots.
